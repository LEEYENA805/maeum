# 마음이 - 기억돌봄 웹사이트 프로토타입

## 실행 방법
1. 이 폴더 전체를 PyCharm에서 엽니다.
2. `index.html`을 Chrome에서 실행합니다.
3. 마이크 버튼을 누르면 한국어 음성 인식을 시작합니다.
4. 말한 내용은 채팅 기록에 저장되고, 캐릭터가 따뜻한 답변과 기억을 떠올리는 질문을 이어갑니다.
5. `설정 → 개인정보`에서 보호자 전화번호를 저장하면 `자녀에게 전화` 버튼으로 연결할 수 있습니다.

## 현재 구현된 기능
- 첫 화면을 첨부 이미지와 비슷한 따뜻한 UI로 구성
- 여자/남자 캐릭터 전환
- 한국어 음성 인식(Web Speech API)
- 대화 내용 localStorage 저장
- 대화기록 보기
- 기억 회상 질문 로직
- 따뜻한 캐릭터 답변 + 음성 읽기
- 사용자/보호자 정보 입력
- 보호자 전화번호 저장 및 전화 버튼
- 119 전화 전 확인창
- 브라우저 위치 권한을 확인한 뒤 119 연결 시도
- 모바일/PC 반응형

## 중요한 점
- 이 버전은 **프론트엔드 프로토타입**이라 AI가 자유롭게 답변하는 것이 아니라 질문/답변 로직을 사용합니다.
- 실제 서비스에서 사용자의 말을 더 잘 이해하고 자연스럽게 대화하려면 Flask 같은 백엔드에서 AI API를 연결하는 것이 좋습니다.
- 브라우저에서는 긴급전화의 '가장 가까운 기관 번호를 직접 선택'하는 방식보다 `119`로 연결하는 것이 일반적입니다. 실제 출동 기관의 위치 판단은 119 시스템에서 처리됩니다.
- 음성 인식은 Chrome 등 지원 브라우저와 마이크 권한이 필요합니다.
- 개인정보와 대화 내용은 현재 브라우저의 localStorage에 저장됩니다. 실제 서비스에서는 암호화, 접근권한, 삭제정책 등을 별도로 설계해야 합니다.
